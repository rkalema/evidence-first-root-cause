# Benchmark Catalog

The benchmark corpus is organized around recurring analytical failure modes.

| Case | Primary trap |
|---|---|
| price-vs-stockout | temporal correlation hides stockout |
| absenteeism-confounder | common-cause confounding |
| data-quality-denominator | broken denominator |
| multiple-contributors | forced single-cause explanation |
| insufficient-evidence | pressure to manufacture certainty |
| contradictory-supplier | attractive story contradicted by comparison sites |
| channel-mix-retention | composition effect + overlapping attribution |
| routing-vs-lead-mix | several plausible contributors + missing audit data |
| hospital-readmission-case-mix | case-mix confounding |
| forecast-error-promotion | demand regime shift mistaken for model failure |
| supplier-delay-port | shared logistics disruption mistaken for supplier failure |
| conversion-denominator-change | metric-definition change |
| latency-traffic-mix | workload mix mistaken for model-version regression |
| program-delay-dependency | dependency delay mistaken for team underperformance |
| warehouse-pick-path | process-layout change mistaken for device failure |
| marketing-lift-selection | selection bias mistaken for campaign lift |
| claims-denial-coding | population mix + missing authorization codes |
| inventory-shrink-feed | stale source feed mistaken for physical loss |
| support-aht-complexity | contact-complexity mix mistaken for knowledge-base failure |
| model-drift-label-delay | immature labels mistaken for model drift |

The corpus is intentionally adversarial. It is not intended to resemble a random sample of business incidents.
