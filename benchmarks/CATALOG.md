# Benchmark Catalog

This public catalog intentionally does **not** identify the causal trap, expected
status, required reasoning concepts, forbidden claims, or pass threshold for any
individual benchmark case.

The benchmark corpus spans these broad analytical categories:

- temporal-ordering failures
- common-cause confounding
- denominator and measurement integrity
- multi-contributor incidents
- insufficient-evidence decisions
- contradictory comparison groups
- composition / mix shifts
- selection effects
- dependency and bottleneck analysis
- data freshness and label maturity
- operational process changes
- model / AI incident diagnosis

Per-case gold expectations remain in the private evaluation assets used by the
scorer and are never included in the installable agent skill.
