# Example: Healthcare Claims

## Scenario

A health system reports that commercial-payer outpatient claim denials increased from 6.2% to 10.9% in one week.

## Evidence-first questions

Before explaining the increase:

1. Did claim volume change?
2. Did the denial-rate denominator change?
3. Did a payer feed arrive late or duplicate?
4. Is the increase concentrated by payer, CPT group, facility, provider, or denial code?
5. Did coding, authorization, eligibility, or claim-scrubbing rules change before the increase?
6. Which competing explanation would produce a different observable pattern?

## Example hypotheses

- prior-authorization workflow failure
- payer rule change
- coding change
- eligibility verification failure
- claim-submission formatting change
- reporting/pipeline artifact

The skill should not conclude "payer behavior changed" merely because payer denials increased.
