# Evidence-First Methodology

Evidence-First separates evidence acquisition, signal validation, hypothesis generation, analytical testing, contradiction search, confound review, contribution estimation, independent critique, action planning, outcome evaluation, and institutional memory.

The method is designed around one constraint: an explanation is not promoted because it is plausible; it is promoted only when its predicted evidence survives attempts to disprove it.

Claims are typed as observation, inference, conclusion, or unknown. Source evidence is fingerprinted. Derived evidence records the tool and source identifiers used to create it. Contradictory evidence remains visible. Numerical attribution is withheld when overlapping causes or missing denominators make decomposition unsafe.

A full investigation is not closed when an explanation is written. It is closed only after the intervention is measured against declared success and falsification criteria, or the system explicitly records that outcome evidence is unavailable.
